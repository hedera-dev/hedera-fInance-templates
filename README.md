# Hedera finance templates

Each template lives on its own branch.

```bash
npx create-scaffold-hbar@latest --template hedera-dev/hedera-fInance-templates#templates/dvp-settlement
```

| Branch | Template |
| --- | --- |
| `templates/dvp-settlement` | Settle a trade delivery-versus-payment in one atomic transfer |

Bond issuance, coupon payments, and the HCS audit trail will each land on a `templates/*` branch.
